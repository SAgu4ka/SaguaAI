# Saguka AI — ROB RUN RNG Analyzer

Исследовательский инструмент для Android: вы вручную вносите результаты ROB RUN, приложение
**на лету дообучает нейросеть и набор статистических моделей** и честно проверяет, есть ли в
выпадениях хоть какая-то предсказуемость.

Kotlin + Jetpack Compose + Room. Без интернета, без регистрации, без платных API. Android 10+.

## Что внутри

| Часть | Файлы |
|---|---|
| Ядро ML (чистый Kotlin, без Android) | `app/src/main/java/ru/sagu4ka/rngai/ml/` |
| Хранение (Room) и экспорт/импорт | `.../data/` |
| ViewModel — держит и дообучает движок | `.../AppViewModel.kt` |
| Интерфейс (6 вкладок) | `.../ui/` |
| Симуляция для проверки ядра | `verify/Sim.kt` |

### Модели
- **A** — историческая частота + сглаживание Лапласа
- **B** — скользящие окна 10 / 25 / 50 / 100
- **C** — марковские цепи 1-го и 2-го порядка (иерархическая усадка)
- **D** — поиск повторяющихся последовательностей (самое длинное совпадение хвоста, длины 2–8)
- **Колесо** — смещение соседних карманов и «подпись броска» (шаг между выпадениями на колесе)
- **Нейросеть** — перцептрон (скрытый слой 24, tanh, softmax), обучается онлайн после каждого результата
  + повторное обучение на буфере последних примеров. Выход стартует с нуля, поэтому до обучения даёт ровно 1/K
- **E (ансамбль)** — Hedge-взвешивание всех моделей по недавней ошибке на ещё не виденных данных

### Как не обмануть себя
Все модели работают строго «сначала прогноз → потом результат» (prequential-проверка), поэтому утечки
между обучением и проверкой нет. Накопленное преимущество ансамбля над равномерной моделью считается как
**e-процесс** (тестовый мартингал). По неравенству Виля вероятность того, что он когда-либо дойдёт до порога
100 на честном ГСЧ, не больше 1 % — даже если смотреть на него после каждого спина. Прогноз показывается только
когда:
1. накоплено ≥ 200 результатов,
2. капитал ≥ ln(100),
3. ансамбль выигрывает у случайного и в последних 200 спинах.

Иначе приложение показывает ровно 1/K для каждого сектора и пишет, что закономерностей не найдено.

### Результаты симуляции ядра (3000 спинов)

| Сценарий | Результат |
|---|---|
| Честное колесо | 0 ложных срабатываний из 40 |
| Сектор 17 и соседи выпадают втрое чаще | найдено в 20 из 20, медиана ≈ 240-й спин |
| После x с шансом 20 % идёт x+1 | найдено в 20 из 20, медиана ≈ 400-й спин |
| «Подпись броска» (шаг +9…+11) | найдено в 20 из 20, медиана ≈ 200-й спин |

Запуск симуляции: `kotlinc app/src/main/java/ru/sagu4ka/rngai/ml/*.kt verify/Sim.kt -include-runtime -d sim.jar && java -jar sim.jar 40 3000`

> Часть интерфейса (Compose) писалась без запуска Android-сборки. Если Gradle найдёт опечатку — это
> мелочь, исправляется за минуты; ядро `ml/` скомпилировано и проверено.

## Сборка APK

### Вариант 1. Без Android Studio — через GitHub (проще всего)
1. Создайте пустой репозиторий на GitHub и загрузите в него всё содержимое этой папки.
2. Откройте вкладку **Actions** → «Сборка APK» → **Run workflow** (запускается и сам при каждом push).
3. Через 5–8 минут откройте завершённый запуск и скачайте артефакт **SagukaAI-apk** — внутри `app-release.apk`.
4. Перенесите APK на телефон и установите (разрешите установку из неизвестных источников).

### Вариант 2. Android Studio
1. Установите Android Studio (Ladybug или новее).
2. `File → Open` → выберите папку проекта, дождитесь синхронизации Gradle.
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
4. APK появится в `app/build/outputs/apk/`.

### Вариант 3. Командная строка
Нужны JDK 17 и Android SDK (платформа 35):
```
export ANDROID_HOME=/путь/к/sdk
./gradlew assembleRelease
```
Файл: `app/build/outputs/apk/release/app-release.apk` (подписан отладочным ключом — для личной установки достаточно).
